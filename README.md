## 📦 Installation & Setup

### Prerequisites
```bash
- Node.js v16+
- npm atau yarn
- Git
```

### Instalasi

1. **Clone Repository**
```bash
git clone https://github.com/cHalls-claud/-halls-ai-os-final-project.git
cd -halls-ai-os-final-project
```

2. **Install Dependencies**
```bash
npm install
# atau
yarn install
```

3. **Setup Environment Variables**
```bash
cp .env.example .env
# Edit .env dengan konfigurasi Anda
```

4. **Run Project**
```bash
npm start
# atau
yarn start
```

5. **Access Applications**
```
- Main App: http://localhost:3000
- Admin Panel: http://localhost:3000/admin
- Dashboard: http://localhost:3000/dashboard
```

## 🔧 Configuration

### Environment Variables (.env)

```env
# Server
PORT=3000
NODE_ENV=development

# Database
DB_HOST=localhost
DB_PORT=27017
DB_NAME=halls_ai_os

# Authentication
JWT_SECRET=your_secret_key_here
JWT_EXPIRE=7d

# OAuth
GOOGLE_CLIENT_ID=xxx
GOOGLE_CLIENT_SECRET=xxx

# Bot
BOT_TOKEN=xxx
BOT_WEBHOOK_URL=xxx

EMAIL_SERVICE=gmail
```
